6. FULL CONVERSATION TEST: ASHLEY + TRANSCRIPTS + GEMINI + UNITY PANELS
-----------------------------------------------------------------------

This command configures "hi" as the start trigger only inside the test process.
It streams these utterances through POST /utterance:

  random text
  what da hell
  hi how are you
  im good thanks, what about you
  im doing not so great
  today i tripped and fell and it hurt
  oh i am so sorry

Run:

  GEMINI_MODEL=gemini-3.1-flash-lite \
  MPLCONFIGDIR=/tmp/hackthenorth-mpl \
    .venv/bin/python -m server.simulate_conversation \
    "/Users/andrewdeng/Desktop/Screenshot 2026-09-20 at 5.57.33 AM.png"

This test asserts all of the following:

  - "random text" and "what da hell" do not enter conversation memory.
  - "hi" starts a clean conversation session.
  - The trigger word is removed; "how are you" is the first stored chunk.
  - Transcript ingestion finishes before the gated identity result is released.
  - The picture resolves to ashley-moon.
  - Gemini receives concise research first, then verbose research.
  - Gemini receives all five post-trigger transcript chunks in order.
  - research_ready occurs before talking_points_ready.
  - GET /conversation/panel1 returns Ashley's concise research.
  - GET /conversation/panel2 returns Gemini's talking points.

Expected final line:

  all end-to-end assertions passed

This process-local configuration overrides server/.env without editing it.
Leave this terminal running for the curl tests below.
